# 시니어가드 (SeniorGuard)

고령자가 보이스피싱·스미싱 문자에 돈을 보내기 전에 멈추고, 가족에게 바로 확인할 수 있도록 돕는 웹앱입니다.
아이폰 사파리에서 '홈 화면에 추가'하면 앱처럼 쓸 수 있습니다.

> "전화는 통신사가, 마지막 송금 버튼 앞에는 시니어가드가."

## 기능

| 기능 | 설명 |
| --- | --- |
| 화면 검사하기 | 문자·카톡 캡처 사진의 글자를 휴대폰 안에서 읽어 판정 (사진은 외부로 보내지 않음) |
| 문자 글자로 검사하기 | 붙여넣은 글자를 즉시 판정. 사기 유형 10종, 단축 주소·가짜 도메인·앱 설치 링크 탐지 |
| 방금 전화가 이상했어요 | 7개 질문으로 통화 위험도 판정 (통화를 녹음하거나 듣지 않음) |
| 가족 연락처 | 위험할 때 저장된 진짜 번호로 확인 전화. 번호는 이 기기에만 저장 |
| 112 신고·대처법 | 지급정지, 금융감독원 1332, 한국인터넷진흥원 118 안내 |
| 사기 전화 체험 | 위험도가 0%에서 97%로 오르는 과정을 보여주는 시연 모드 (시연용 수치) |
| 단축어 연동 | `?text=` 주소로 글자를 넘기면 바로 결과 화면 표시 |

판정 원칙: 신호가 하나면 '주의', 둘 이상 겹치면 '위험'. 결과는 참고용입니다.

## GitHub Pages에 올리기 (git 설치 없이, 웹에서)

1. GitHub에 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name에 `seniorguard` 입력 → **Public** 선택 → **Create repository**
3. 만들어진 화면에서 **uploading an existing file** 클릭
4. 이 폴더 **안의 내용 전체**(`index.html`, `manifest.webmanifest`, `.nojekyll`, `README.md`, `icons` 폴더, `assets` 폴더)를 끌어다 놓기 → **Commit changes**
   - `.nojekyll`처럼 점으로 시작하는 파일은 맥 Finder에서 숨겨져 있을 수 있어요. 맥에서는 `Cmd + Shift + .`으로 보이게 할 수 있습니다. 빠져도 앱은 동작합니다.
5. 저장소의 **Settings → Pages** → Source를 **Deploy from a branch**, Branch를 **main / (root)**로 선택 → **Save**
6. 1~2분 뒤 `https://<내 아이디>.github.io/seniorguard/` 주소로 열립니다.

## 아이폰에 설치하기

1. 아이폰 **사파리**에서 위 주소를 엽니다.
2. 아래쪽 **공유 버튼** → **홈 화면에 추가** → **추가**
3. 홈 화면의 시니어가드 아이콘으로 실행합니다.

## 캡처와 동시에 검사하기 (단축어 + 뒷면 탭)

아이폰은 앱이 스크린샷을 자동으로 감지하지 못하게 막아 두었기 때문에, 아이폰 기본 **단축어** 앱을 씁니다.

단축어 앱 → **+** → 이름 "시니어가드 검사" → 동작 추가:

1. **스크린샷 찍기**
2. **이미지에서 텍스트 추출** (입력: 스크린샷)
3. **URL 인코딩** (입력: 추출된 텍스트)
4. **URL 열기**: `https://<내 아이디>.github.io/seniorguard/?text=` 뒤에 3번 결과 변수를 붙이기

그다음 **설정 → 손쉬운 사용 → 터치 → 뒷면 탭 → 이중 탭**에 "시니어가드 검사"를 연결하면, 아이폰 뒷면을 두 번 톡톡 치는 것만으로 캡처와 검사가 한 번에 됩니다.

> 이 방식은 문자 글자가 주소에 담겨 GitHub 서버로 전달됩니다. 이것이 싫다면 단축어 안에서 단어 일치로만 판정하는 방식(인터넷 없이 동작)을 쓰세요.

## 개인정보

- 캡처 사진의 글자 인식은 휴대폰 안에서 처리합니다. 처음 한 번만 글자 인식 프로그램과 한글 데이터를 인터넷(jsDelivr)에서 받아 옵니다.
- 가족 번호, 글씨 크기 설정은 이 기기의 브라우저에만 저장됩니다.
- 서버나 회원가입이 없습니다.

## 파일 구성

```
index.html            앱 전체 (화면, 판정 엔진, 글자 인식 연결)
manifest.webmanifest  홈 화면 설치 정보
icons/                앱 아이콘 (180·192·512·1024px, 파비콘)
assets/               로고 이미지
.nojekyll             GitHub Pages가 파일을 그대로 쓰도록 하는 설정
```

## 한계

- 일반 전화의 실시간 통화 음성은 운영체제가 막아 두어 분석하지 않습니다. 통화 중 탐지는 통신사 앱(후후·에이닷·익시오)과 함께 쓰세요.
- 판정은 규칙 기반이라 새로운 수법을 놓치거나, 정상 문자를 주의로 볼 수 있습니다.
